## 🔑 Por que este jardim é só seu?

Porque ele foi plantado assim: **com uma única chave, e essa chave é você.**

- 🌻 **Não existe login de outras pessoas.** Só o seu nome abre a porta: `Celi` ou `Celina`.
- 💾 **Tudo que você conquista fica com você.** Moedas, corações e poesias moram no seu aparelho — ninguém mais vê.
- 📅 **Suas mensagens são suas.** A edição de cada dia é escrita pensando em um único leitor: você.
- 🤫 **Seu histórico é privado.** O que você guarda, lê e salva pertence só ao seu cantinho.

*Em um mundo de coisas compartilhadas, este é um lugar que é inteiramente seu.*

## 🌅 Um ritual sugerido (só se você quiser)

```
1. Abra o jardim pela manhã.
   → Colete seu bônus diário de +3 💛 (ele espera por você).

2. Leia a Mensagem do Dia devagar.
   → Se uma frase te abraçar, toque em "Salvar no Meu Coração".

3. Brinque um pouquinho.
   → Uma rodada de Quiz ou uma Chuva de Flores já muda o humor.

4. Se o dia estiver pesado, vá às Poesias.
   → Tem um verso certo pra cada tipo de dia difícil.

5. Antes de fechar, respire.
   → O jardim estará aqui amanhã. E depois. E sempre.
~~~

*Nada disso é obrigação. É convite.*
